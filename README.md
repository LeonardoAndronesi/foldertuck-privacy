# FolderTuck Privacy Policy

Effective 9 November 2026

This policy applies to **FolderTuck: File Organizer** (Android package `com.leonardo.myfiles`), developed by [LeonardoAndronesi](https://github.com/LeonardoAndronesi).

## Data collection

FolderTuck does not collect user data or send it to the developer. The app has no accounts, ads, analytics, or tracking.

## File access and storage

FolderTuck uses Android's file picker to access the files you select. It reads them to show file information and previews, and remembers the access granted by Android so you can reopen them. Folder names, display names, file references, file types, and app preferences are kept in the app's private storage on your device. Previews are generated on the device.

## Opening, sharing, and exporting

When you choose to open or share a file, FolderTuck gives the app you select read access to that file. If you export your organisation, FolderTuck writes a JSON file containing your folder names, display names, and file references to the destination you choose. The export contains no original file contents. Apps and storage providers you choose, including cloud providers, handle that information under their own privacy policies.

## Retention and deletion

FolderTuck keeps your organisation on the device until you remove items, clear the app's storage, or uninstall it. Clearing storage or uninstalling removes the app's saved data and leaves your original files and any exports you saved. You can delete exports from the location where you saved them.

## Contact

Send privacy questions through the [FolderTuck issue tracker](https://github.com/LeonardoAndronesi/foldertuck-privacy/issues/new). Issues are public, so leave out file contents and personal information.
